How to calculate the TCO
i
TCO Guidance & Budget Validation Terms
The budget amounts below are calculated using the Belgian lump-sum value formula. Pluxee provides informational Total Cost of Ownership guidance only, not a legal TCO certification. Pluxee is not responsible for these budget amounts. This is a draft calculation to help you get started. You are responsible for validating and approving the final budget amounts for your organization.
Formula we use:
For rented/leased cars: Fixed component (annual rental + costs + VAT + taxes + CO2 contribution) + Variable component [(6,000 + commuting distance × 2 × 200) × €0.127/km]
For owned/financed cars: Fixed component (catalogue value × 25% + CO2 contribution) + Variable component [(6,000 + commuting distance × 2 × 200) × €0.127/km]
